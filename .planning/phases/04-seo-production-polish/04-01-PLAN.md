    3. Update `src/components/sections/ContactForm.astro`:
       - In the `<script>` block, after the successful submission branch (`if (response.ok && result.success)`), add Plausible event tracking BEFORE showMessage:
         ```typescript
         // Track contact form conversion
         (window as any).plausible('ContactFormSubmit', {
           props: {
             clubName: clubName,
             memberRange: formData.get('member_count')?.toString() || 'not-specified'
           }
         });
         ```

    4. Update `src/styles/global.css`:
       - Add `prefers-reduced-motion` media query that disables all transitions, animations, and smooth scrolling:
         ```css
         @media (prefers-reduced-motion: reduce) {
           *, *::before, *::after {
             animation-duration: 0.01ms !important;
             animation-iteration-count: 1 !important;
             transition-duration: 0.01ms !important;
             scroll-behavior: auto !important;
           }
         }
         ```
         This global approach (using `*` selector with `!important`) catches ALL component transitions without needing to modify each component file individually. Using 0.01ms instead of 0s ensures animation-end events still fire. This is the recommended modern pattern.
