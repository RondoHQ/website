  <files>

  <action>
    Create four Astro components in `src/components/ui/`. All components use Tailwind utility classes from the theme established in Plan 01 combined with scoped `<style>` blocks for glass morphism effects that need vendor prefixes and media queries.

    **GlassPanel.astro** -- Base translucent container. Props: `class` (optional extra classes). Features:
    - `background: rgba(255, 255, 255, 0.05)` with `backdrop-filter: blur(10px)` and `-webkit-backdrop-filter: blur(10px)`
    - `border: 1px solid rgba(255, 255, 255, 0.1)`
    - `box-shadow: 0 8px 32px 0 rgba(30, 58, 138, 0.3)` (deep-midnight toned shadow)
    - `border-radius: 1rem`
    - Mobile: reduce blur to `6px` via `@media (max-width: 768px)`
    - Accessibility: `@media (prefers-reduced-transparency)` removes blur, increases background opacity to `rgba(255, 255, 255, 0.15)`
    - Fallback: `@supports not (backdrop-filter: blur(10px))` provides solid alternative
    - Uses `<slot />` for content

    **Card.astro** -- Extends glass panel concept for content cards. Props: `title` (optional string), `class` (optional). Features:
    - Same glass morphism base as GlassPanel
    - Padding: `p-6 md:p-8`
    - If title prop provided, renders `<h3>` with `text-white font-semibold text-xl` (pure white for 4.5:1 contrast)
    - Content via `<slot />`
    - Hover state: subtle brightness increase `background: rgba(255, 255, 255, 0.08)`
    - Includes all the same accessibility/mobile/fallback rules as GlassPanel

    **Button.astro** -- Three variants. Props: `variant` ('primary' | 'secondary' | 'glass', default 'primary'), `href` (optional -- renders as `<a>` if provided, `<button>` otherwise), `class` (optional), `type` (optional, for form buttons). Features:
    - **Primary**: `bg-electric-cyan text-obsidian` (dark text on cyan -- excellent contrast). Hover: darken slightly, add cyan glow shadow `box-shadow: 0 10px 20px rgba(34, 211, 238, 0.3)`, `translateY(-2px)`.
    - **Secondary**: `bg-bright-cobalt text-white`. Hover: darken, blue glow shadow, translateY(-2px).
    - **Glass**: translucent `rgba(255, 255, 255, 0.1)` with `backdrop-filter: blur(10px)`, white text, white border. Hover: increase opacity. Same prefers-reduced-transparency and mobile rules.
    - All variants: `inline-flex items-center justify-center`, `px-6 py-3`, `rounded-lg`, `font-semibold`, `transition-all duration-200`, `cursor-pointer`, no default border.
    - Uses `<slot />` for button text.

    **Input.astro** -- Form input for dark background. Props: `label` (string), `name` (string), `type` (string, default 'text'), `placeholder` (optional string), `required` (boolean, default false), `class` (optional). Features:
    - Wraps a `<label>` and `<input>` together
    - Label: `text-sm font-medium text-gray-300 mb-1` (readable on dark bg)
    - Input: glass-style background `rgba(255, 255, 255, 0.05)`, `border: 1px solid rgba(255, 255, 255, 0.15)`, `text-white`, `rounded-lg`, `px-4 py-3`
    - Focus: `border-color: #22D3EE` (electric-cyan), `ring` with cyan glow, `outline-none`
    - Placeholder: `text-gray-500`
    - Same prefers-reduced-transparency and mobile rules for the glass background
