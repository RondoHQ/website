If the scaffolding tool creates conflicts, create files manually instead.

    **package.json**: Ensure these dependencies:
    - `astro` (^5.17.0 or latest 5.x)
    - `tailwindcss` (^4.0.0)
    - `@tailwindcss/vite` (latest)
    - Scripts: `dev`, `build`, `preview` (standard Astro scripts)
    - `"engines": { "node": ">=22.0.0" }`

    Run `npm install` after setting up package.json.

    **astro.config.mjs**: Configure with Tailwind 4 Vite plugin (NOT @astrojs/tailwind which is deprecated for v4):
    ```javascript
    import { defineConfig } from 'astro/config';
    import tailwindcss from '@tailwindcss/vite';

    export default defineConfig({
      vite: {
        plugins: [tailwindcss()]
      }
    });
    ```

    **tsconfig.json**: Use Astro's recommended TypeScript config with `"extends": "astro/tsconfigs/strict"`.

    **.nvmrc**: Create with content `22` for Cloudflare Pages compatibility.

    **.gitignore**: Ensure it includes standard Astro ignores: `node_modules/`, `dist/`, `.astro/`. Do NOT gitignore `.planning/`.
  </action>
  <verify>
    Run `npm run build` -- should complete without errors and produce `dist/` directory.
    Run `node -v` -- should show v22.x.
    Verify `astro.config.mjs` contains `tailwindcss()` in vite plugins.
    Verify `.nvmrc` contains `22`.
  </verify>
  <done>
    Astro project builds successfully. Tailwind CSS 4 is installed via @tailwindcss/vite plugin. Node 22 is pinned via .nvmrc. TypeScript is configured.

    ```css

    @theme {
      --color-electric-cyan: #22D3EE;
      --color-bright-cobalt: #3B82F6;
      --color-deep-midnight: #1E3A8A;
      --color-obsidian: #0F172A;
    }

    body {
      font-family: system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
      -webkit-font-smoothing: antialiased;
      -moz-osx-font-smoothing: grayscale;
    }
    ```
