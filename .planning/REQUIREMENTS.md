# Requirements: Rondo Website

**Defined:** 2026-02-06
**Core Value:** Clearly communicate what Rondo does and make it effortless for sports clubs to get in touch

## v1 Requirements

### Hero & Brand

- [ ] **HERO-01**: Landing page has an outcome-focused Dutch headline (<8 words) with supporting subline
- [ ] **HERO-02**: Hero section includes a real product visual/screenshot of Rondo Club
- [ ] **HERO-03**: Primary CTA button visible above the fold
- [ ] **HERO-04**: Header with Rondo logo and simple navigation

### Products

- [ ] **PROD-01**: Dedicated section explaining Rondo Club — people, teams, and dates management
- [ ] **PROD-02**: Dedicated section explaining Rondo Sync — automated data sync from Sportlink
- [ ] **PROD-03**: Integration diagram showing how Club, Sync, Sportlink, Laposta, and FreeScout connect

### Pricing

- [ ] **PRIC-01**: Pricing section displaying the formula: minimum €250/jaar + €0,50 per lid per jaar with example calculation

### Contact

- [ ] **CONT-01**: Contact form with fields: name, email, club name, member count (optional), message (optional)

### Design

- [ ] **DSGN-01**: Soft glass morphism aesthetic with electric cyan (#22D3EE) and bright cobalt (#3B82F6) accents
- [ ] **DSGN-02**: Dark obsidian background (#0F172A) with subtle texture
- [ ] **DSGN-03**: Deep midnight blue (#1E3A8A) for shadows and depth
- [ ] **DSGN-04**: Responsive mobile-first design

### Technical

- [ ] **TECH-01**: Built with Astro 5.17+ and Tailwind CSS 4
- [ ] **TECH-02**: Deployed to Cloudflare Pages
- [ ] **TECH-03**: SEO meta tags (title, description, OpenGraph) for social sharing
- [ ] **TECH-04**: Plausible analytics integration
- [ ] **TECH-05**: Dutch language throughout

## v2 Requirements

### Trust & Social Proof

- **TRST-01**: Customer testimonials from real clubs
- **TRST-02**: Club logos of organizations using Rondo
- **TRST-03**: Stats/numbers (e.g. "Vertrouwd door X+ verenigingen")

### Enhanced Pricing

- **PRIC-02**: Interactive pricing calculator (enter member count, see price)
- **PRIC-03**: Feature list showing what's included

### Content Growth

- **GROW-01**: Additional product detail pages for Club and Sync
- **GROW-02**: Blog/content section
- **GROW-03**: Case studies with metrics

### Interactive

- **INTR-01**: Micro-animations on scroll
- **INTR-02**: Interactive product preview/demo

## Out of Scope

| Feature | Reason |
|---------|--------|
| English / multi-language | Dutch-only audience for now |
| User authentication / dashboard | Marketing site, not the app |
| Online signup / self-serve payment | Manual onboarding via contact form |
| Blog / CMS | Landing page only for v1 |
| Video testimonials | Need customer cooperation, defer to v2 |
| ROI calculator | Need validated customer data first |
| Chatbot | Target audience prefers email/form |
