# Volunteer statistics KPI definitions

These definitions document the labels shown on **Vrijwilligers → Statistieken**. They are based on published, non-cancelled signup tasks in the selected sports season.

| Label | Definition |
| --- | --- |
| Signups | Current person-to-task assignments. Cancelled tasks are excluded. |
| Available places | Sum of task capacity, with at least one slot per published task. |
| Volunteers | Unique people with at least one current assignment. |
| Fill rate | Current signups divided by available slots, expressed as a percentage. |
| Completed / upcoming | Assignments on completed tasks versus assignments on tasks whose start time is still in the future. |
| Average | Current signups divided by unique volunteers. |
| Signups per task type | Current assignments grouped by task type, with each type's share of all assignments. |
| Fill rate per task type | Current assignments for that type divided by its available slots. |
| Signup trend | Cumulative current assignments by recorded member-signup time, using coordinator-assignment time as a fallback. It is a view of current assignments, not a historical cancellation ledger. |
| Distribution | Number of volunteers with one, two, or at least three current assignments. |
| Volunteer-obligation progress | Eligible household or player units split into completed, sufficiently scheduled, partially scheduled, not started, and exempt. |
| Upcoming shortages | Published tasks in the next 30 days with fewer current assignments than available slots, ordered by date. The dashboard shows the first 12. |

The dashboard offers the current and previous sports season. A controlled reconciliation against the source tasks and assignments remains required as product proof.
